How to read the metrics

MAE

Mean absolute error. Average miss in kilograms; it is used to rank models.

RMSE

Root mean squared error. Penalizes larger errors more heavily.

R²

Explained variance relative to predicting the test-set mean; can be negative.

Evaluation uses a reproducible 80/20 holdout split. Validate further with representative future-period data.
